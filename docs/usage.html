按 README 在本地运行

下面三步来自仓库 README，没有改步骤、也没有补仓库里没有写的安装细节。

不能在这个网页里运行模型。 需要本机（或你自己的机器）上的 GPU、已安装的 GPU 版 torch、以及按第一步取到的权重。本站只是说明。

  1. 获取权重

    README 写的是用 git-lfs 克隆 NousResearch 的 Llama-2-70b-chat-hf：

    git lfs install
git clone https://huggingface.co/NousResearch/Llama-2-70b-chat-hf

  2. 安装依赖

    README 列出两行 pip，并注明 torch 要用 GPU 版本：

    pip install transformers
pip install torch # gpu 版本

  3. 进行推理

    README 的运行命令是：

    python hg8gpu.py

    脚本会进入 You: 提示的循环。输入 exit（大小写不敏感）后打印 Goodbye! 并销毁进程组。

和脚本加载路径的差异

README 克隆的仓库 ID 是 NousResearch/Llama-2-70b-chat-hf。脚本里 from_pretrained 写的是 meta-llama/Llama-2-70b-chat-hf。仓库没有说明如何把本地克隆目录传给脚本。运行前需要自己核对权重从哪里加载。

运行时脚本会向你要什么

  • 标准输入：每一轮用户句子。
  • 本地 GPU 与 NCCL：脚本会 init_process_group，地址为 tcp://localhost:23456。
  • 能被 transformers 解析的 meta-llama/Llama-2-70b-chat-hf（或你改过之后的路径）。

README 没有写 CUDA 版本、显卡型号或显存要求。本页也不补充未经仓库记载的数字。

内容只依据本仓库的 README.md 与 hg8gpu.py。未收录权重或密钥。
