仓库说明 · 不是演示产品

用 transformers 做 Llama-2 分布式推理的公开脚本

README 原句：llama2 使用 Hugging Face 的 transformers API 进行分布式推理。仓库里目前只有两份文件：README.md 和 hg8gpu.py。

This is a static documentation site, not a live browser inference demo.

这不是浏览器里的在线推理演示。 本站不会加载模型、不会调用 GPU、也不会返回生成结果。要按 README 跑起来，需要本机 GPU、Hugging Face 上的权重，以及 GPU 版 PyTorch，然后在本地执行 python hg8gpu.py。

仓库里有什么

  • README.md：获取权重、安装依赖、运行脚本三步。
  • hg8gpu.py：约 50 行的交互式推理脚本。文件名暗示 8 张 GPU，但实现很薄，详见架构。

仓库不包含模型权重、密钥或运行日志。本站也不收录这些内容。

能从源码直接确认的事

  • 脚本走 Hugging Face transformers：AutoTokenizer 与 AutoModelForCausalLM。
  • 多 GPU 相关代码是 torch.distributed + DistributedDataParallel，不是 Hugging Face 的 device_map。
  • 整模先 .to(device_ids[0])，也就是先放到 GPU 0。
  • 随后进入 input() 对话循环，model.generate(..., max_length=200)，输入 exit 结束。

以上都是对源码的转述。仓库没有给出吞吐、显存、延迟或生产部署数据，本站也不编造。
