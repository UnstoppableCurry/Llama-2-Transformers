范围与非声明

仓库和本站都没有声称的事

这一页把「源码里没有的东西」写清楚，避免把薄脚本读成产品。

这不是实时推理产品页。 没有在线 playground、没有录屏、没有客户名单，也没有编造的 tokens/s 或 VRAM 数字。

本站

  • 静态 HTML。不能在浏览器里加载 Llama-2，也不能替你调用本机 GPU。
  • 文案只整理 README.md 与 hg8gpu.py 里已经写明的内容。
  • 不托管、不镜像模型权重。

脚本没有实现的部分

  • 不是 Hugging Face device_map 分片加载。
  • 不是完整的多进程启动器：没有 torchrun，rank 写死为 0，world_size 却是 8。
  • 注释中的「拆分到多个 GPU」与实际使用的 DDP API 并不对应。
  • 没有 HTTP API、队列、鉴权或多用户服务。
  • 没有测试、配置层或除 hg8gpu.py 以外的运行入口。

因此，不能根据文件名 hg8gpu.py 或 num_gpus = 8 推断「已经实现 8 卡生产推理」。

README 与脚本之间已知的缺口

  • 权重来源：README 克隆 NousResearch/Llama-2-70b-chat-hf，脚本加载 meta-llama/Llama-2-70b-chat-hf。
  • README 没有把本地目录接到 from_pretrained。
  • README 只写「torch # gpu 版本」，没有锁定版本号。

明确不提供的数字与素材

  • 吞吐、延迟、显存占用、卡数利用率。
  • 生产环境截图或「已上线」陈述。
  • 客户、案例或对比评测。

若你要判断脚本在自己的机器上能不能跑通，只能在本地按用法去试，并以架构里的调用为准。

内容只依据本仓库的 README.md 与 hg8gpu.py。未收录权重或密钥。
